# A股复盘知识库

按周期、日期、板块与个股沉淀 A 股情绪和主线切换复盘。

<div class="vp-doc">

## 使用方式

- 在 Obsidian 中打开本目录 `docs/`，直接新增或编辑 Markdown 笔记。
- 只将可公开内容提交到 Git；`docs/private/` 用于本地私密草稿，已被忽略。
- 合并到 `main` 后，Vercel 自动更新生产站；分支和 Pull Request 用于预览核对。

## 内容入口

- [行情周期](/cycles/)：完整周期中的主线切换与承接复盘。
- [日期节点](/timeline/)：分歧、修复、确认、高潮、退潮的明确日期。
- [板块](/sectors/)：板块逻辑、梯队与阶段表现。
- [个股](/stocks/)：业务、题材归属与历史关键节点。

## 记录原则

每篇研究都应先给出背景，再写清楚日期拐点和后续验证，最后归纳板块、核心股、结论与风险。
